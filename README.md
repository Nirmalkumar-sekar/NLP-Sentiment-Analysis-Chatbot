NLP Sentiment Analysis Chatbot

Project Overview
This project is a simple chatbot developed using Python and Natural Language Processing (NLP). It identifies user intent and analyzes sentiment as positive or negative to generate relevant responses.

Features
- Text input from users
- Tokenization using NLTK
- Basic intent detection
- Positive and negative sentiment analysis
- Rule-based chatbot responses
- Exit option using `bye`, `exit`, or `quit`

Technologies Used
- Python
- NLTK
- Natural Language Processing (NLP)

How It Works
1. The user enters a message.
2. The chatbot tokenizes the message.
3. It identifies the topic or intent.
4. It checks sentiment words to classify the message as positive or negative.
5. It returns a response based on the detected intent and sentiment.

Learning Outcomes
- Understanding text tokenization
- Working with dictionaries and sets
- Creating Python functions
- Implementing rule-based intent detection
- Understanding basic sentiment analysis

Limitations
This project uses predefined keywords and rules. It does not understand every sentence or context like a trained machine learning model.

Future Improvements
- Add more intents and response categories
- Improve handling of negation
- Train a machine learning sentiment classifier
- Add a graphical user interface or voice interaction
